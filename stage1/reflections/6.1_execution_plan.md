My stage 1 practice set is Home Credit Default Risk on Kaggle, predicting whether an applicant repays. I'm treating it as a portfolio project to build good habits for the structured BBO challenge in Stage 2, not as the graded capstone itself.

Time management. About 10 hours a week, in weekly milestones so I don't spend three weeks on data exploration and never reach a model. Week 1, cleaning, with a focus on missing data since the main file is roughly 30 percent missing. Week 2, a logistic regression baseline submitted early so the pipeline works end to end.Weeks 3 to 4, feature engineering.Week 5, results and write-up. Roughly 30 percent data, 40 percent modelling, 20 percent docs, 10 percent buffer time.

Model improvement. A results log recording each run: what I changed, the cross-validated AUC, whether it helped. Git for version control so i can roll back. The baseline is my reference point. My rule for new model vs current one: use the cheap wins first, since feature engineering usually moves Home Credit more than swapping algorithms, and only switch model the current one plateaus.

Collaboration. Post specific questions on the board, read how peers frame similar problems, bring problems to office hours. 

Risk management. Biggest risks: leakage from preprocessing or oversampling before the split, overfitting on a wide feature space, and over-tuning for tiny gains.

Mitigations: Al preprocessing inside a pipeline so it only sees training folds, a baseline locked early. I'll review against milestones each weekend.

GitHub strategy. Publish the lot: a README leading with the problem and final AUC in plain english, a commented notebook, and the results log as evidence of disciplined iteration.
